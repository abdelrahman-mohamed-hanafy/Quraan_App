Quraan is a modern Quran application built with Flutter, designed to provide a smooth and user-friendly reading experience.
The app allows users to browse and read all Quran chapters, automatically save their last reading position, and access daily prayer times based on their location.

It follows a clean and scalable architecture using GetX for state management and Hive for efficient local caching, ensuring fast performance and offline accessibility.

🔹 Key Features

Browse and read all Quran chapters

Automatically save and resume last reading position

Quick access to last read chapter

Daily prayer times based on geolocation

Local data caching for offline support

Clean architecture with separated business logic

🔹 Tech Stack

Flutter

GetX

Hive

Supabase

Geolocator
